# 🏋️‍♂️ Fit-Matrix

Fit-Matrix is a dynamic web application built for fitness tracking and management. This project is hosted live via Vercel and configured to update automatically using GitHub.

🚀 Getting Started & Running Locally
To view and test the website on your local machine using main.html, follow these steps:
Method 1: Direct Open
1.	Download or clone this repository to your computer.
2.	Navigate to the project folder.
3.	Double-click on main.html to open it directly in your default web browser.
Method 2: Using VS Code (Recommended for Developers)
1.	Open Visual Studio Code.
2.	Go to File > Open Folder... and select your Fit-Matrix project folder.
3.	For the best development experience with live reloading:
o	Install the Live Server extension from the VS Code Extensions marketplace (Ctrl+Shift+X or Cmd+Shift+X).
o	Right-click on main.html and select "Open with Live Server". This will launch the page in your browser and automatically refresh it whenever you save code changes.
🛠️ Making Changes & Updating the Website
If you want to modify code, styles, or content and have your live Vercel website update automatically:
1.	Make your changes inside VS Code (e.g., editing main.html).
2.	Open the integrated terminal in VS Code (Ctrl + ~ on Windows or Cmd + ~ on Mac).
3.	Stage and commit your changes:
Bash
git add .
git commit -m "Updated main.html with new changes"
4.	Push the changes to GitHub:
Bash
git push origin main
Once pushed, Vercel will automatically detect the updates and refresh your live website within a couple of minutes!
